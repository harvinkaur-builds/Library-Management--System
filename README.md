📚 Library Management System

A console-based Library Management System developed using Python and MySQL to manage books, student records, and library transactions. The project also includes a web scraping module to retrieve book information from websites.

🚀 Features

- Admin Module: Manage student records and library books.
- Student Module: Search for books and view issued books.
- Book Management: Add, update, search, and delete books.
- Student Management: Add and delete student records.
- Library Transactions: View issued and returned books.
- Web Scraping: Extract book information from a website and store the retrieved data in MySQL.
- Database Integration: Store and manage information using MySQL.

🛠️ Technologies Used

- Python
- MySQL
- MySQL Connector for Python
- Web Scraping libraries used in the project
- XAMPP / phpMyAdmin (for local database management)

📂 Project Structure

- "library.py" — Main application file
- "adminmodule.py" — Admin-related operations
- "studentmodule.py" — Student-related operations
- "database.py" — Database connection
- "library.sql" — Database setup script
- "web_scraping.py" — Web scraping functionality

🎯 Learning Outcomes

- Python programming and modular code organization
- MySQL database connectivity and SQL queries
- CRUD operations
- Role-based access and menu-driven applications
- Web scraping and database integration
